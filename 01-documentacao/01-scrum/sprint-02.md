# Sprint 2 — Auditoria de Usabilidade

## 1. Objetivo

Executar os testes de usabilidade definidos no planejamento e avaliar a utilização do GitHub como sistema selecionado para a atividade.

## 2. Duração

A Sprint 2 foi realizada após a conclusão do planejamento da Sprint 1 e teve como foco a execução e documentação dos testes de usabilidade.

## 3. Tarefas realizadas

* executar os testes de usabilidade;
* analisar a navegação;
* analisar a organização da interface;
* analisar a localização das funcionalidades;
* avaliar aspectos relacionados à acessibilidade;
* registrar pontos positivos;
* registrar pontos negativos;
* coletar evidências;
* documentar os resultados;
* elaborar recomendações de melhoria.

## 4. Sistema avaliado

O sistema selecionado foi o GitHub, utilizando o repositório `ProjetoIntegrado3` como ambiente prático para realização dos testes.

## 5. Testes executados

Foram realizados cinco testes:

1. localização e acesso ao repositório;
2. localização e navegação pelos arquivos;
3. localização de Issues;
4. localização de Pull Requests;
5. localização das configurações.

As evidências foram armazenadas no diretório:

`03-evidencias/usabilidade/`

## 6. Resultado

Os testes permitiram avaliar aspectos relacionados à navegação, organização das informações, localização de funcionalidades e clareza da interface.

Os resultados detalhados estão documentados em:

`01-documentacao/02-usabilidade/resultados.md`

As recomendações estão documentadas em:

`01-documentacao/02-usabilidade/recomendacoes.md`

## 7. Problemas e desafios encontrados

O principal desafio identificado foi a quantidade de funcionalidades disponíveis na plataforma e a utilização de terminologia específica, que pode dificultar a utilização por usuários iniciantes.

Também foi identificado que uma avaliação completa de acessibilidade exigiria ferramentas e procedimentos especializados que não fizeram parte desta etapa.

## 8. Melhorias para a próxima Sprint

Para a Sprint 3, o projeto avançará para a análise de hardware e para o desenvolvimento da arquitetura de rede no Cisco Packet Tracer.

As atividades serão concentradas na definição dos componentes recomendados, elaboração da topologia, configuração da rede e realização dos testes de conectividade.
