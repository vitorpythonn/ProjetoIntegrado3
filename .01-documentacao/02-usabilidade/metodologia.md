# Metodologia do Teste de Usabilidade

## 1. Objetivo

O teste de usabilidade tem como objetivo avaliar a facilidade de utilização do GitHub, considerando aspectos relacionados à navegação, organização das informações, localização de funcionalidades, consistência visual, feedback ao usuário e acessibilidade.

## 2. Sistema avaliado

O sistema escolhido para avaliação foi o GitHub, plataforma utilizada para hospedagem e gerenciamento de projetos e repositórios de software.

A avaliação será realizada sobre a interface disponibilizada ao usuário, considerando tarefas comuns de navegação e gerenciamento de um repositório.

## 3. Método de avaliação

A avaliação será realizada por meio da execução de tarefas práticas no GitHub.

Durante cada tarefa serão observados:

* facilidade para localizar a funcionalidade;
* quantidade e clareza das etapas necessárias;
* organização das informações;
* compreensão dos menus e comandos;
* feedback apresentado após as ações;
* consistência da interface;
* possíveis dificuldades de utilização;
* aspectos de acessibilidade perceptíveis durante a utilização.

As observações serão registradas durante a execução e utilizadas posteriormente na elaboração dos resultados.

## 4. Tarefas avaliadas

Serão realizadas as seguintes tarefas:

1. Acessar o GitHub e localizar um repositório.
2. Navegar pela página principal de um repositório.
3. Localizar os arquivos do repositório.
4. Localizar a área de Issues.
5. Localizar a área de Pull Requests.
6. Localizar as configurações do repositório.
7. Localizar informações relacionadas ao código e à atividade do repositório.

As tarefas foram selecionadas por representarem funcionalidades comuns da plataforma.

## 5. Critérios

Cada tarefa será analisada considerando os seguintes critérios:

| Critério            | Aspecto observado                                  |
| ------------------- | -------------------------------------------------- |
| Navegação           | Facilidade para percorrer as áreas do sistema      |
| Menus               | Clareza e compreensão das opções                   |
| Organização         | Disposição das informações                         |
| Localização         | Facilidade para encontrar funcionalidades          |
| Consistência visual | Manutenção dos padrões da interface                |
| Feedback            | Retorno apresentado após ações                     |
| Acessibilidade      | Elementos que facilitam ou dificultam a utilização |

## 6. Registro das evidências

Durante os testes serão realizadas capturas de tela das etapas consideradas relevantes.

As imagens serão armazenadas em:

`03-evidencias/usabilidade/`

As capturas serão utilizadas para comprovar a execução dos testes e fundamentar os resultados apresentados no relatório.

## 7. Análise dos resultados

Após a execução das tarefas, os resultados serão classificados em:

* aspectos positivos;
* aspectos negativos;
* dificuldades encontradas;
* oportunidades de melhoria.

As conclusões serão baseadas nas observações realizadas durante os testes e nas evidências coletadas.
