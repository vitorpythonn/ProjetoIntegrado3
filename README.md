# Projeto Integrado — ADS

Projeto acadêmico desenvolvido individualmente para o curso de Análise e Desenvolvimento de Sistemas.

## Objetivo

Desenvolver um projeto interdisciplinar envolvendo gestão ágil, teste de usabilidade, análise de hardware e arquitetura de rede.

## Estrutura do projeto

```text
01-documentacao/
├── 01-scrum/
├── 02-usabilidade/
├── 03-hardware/
└── 04-rede/

02-packet-tracer/

03-evidencias/
├── trello/
├── usabilidade/
└── packet-tracer/

04-relatorio-final/

05-referencias/
```

## Tecnologias e ferramentas

* Git e GitHub
* Trello
* Cisco Packet Tracer
* Microsoft Word

## Etapas do projeto

1. Gestão ágil e planejamento Scrum.
2. Teste de usabilidade do GitHub.
3. Análise de hardware.
4. Arquitetura de rede com VLANs.
5. Testes de conectividade.
6. Elaboração do relatório acadêmico final.
